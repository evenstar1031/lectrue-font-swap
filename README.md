# 강의자료 글꼴 바꾸기

PDF · PPTX · DOCX 강의자료의 글꼴을 **내가 고른 글꼴**로 바꿔 주는 웹페이지예요. 그림 속 글자는 **OCR로 읽어서 검색되게** 만들고, 실제로 검색이 되는지 **검사 화면**에서 바로 확인할 수 있어요.

- **업로드 없음**: 모든 처리가 내 기기(브라우저) 안에서 일어나요. 강의자료도, 글꼴 파일도 밖으로 안 나가요.
- **고딕/바탕 구분**: 원래 고딕 계열(맑은 고딕, 돋움, 굴림, Arial…)은 고딕으로, 바탕·명조 계열(바탕, 신명조, Times…)은 바탕으로 바꿔요. 어느 쪽인지 모르는 글꼴은 **바탕 보통(기본 본문)** 으로 바꿔요. 굵은 글씨는 굵은 글꼴로.
- **레이아웃 그대로**: PDF는 글자 위치·크기·색·겹침 순서를 건드리지 않고 글꼴만 바꿔요. 기호 글꼴(Wingdings 등)과 새 글꼴에 없는 글자는 원래대로 남겨요.
- **OCR 자동**: 그림·표 이미지 안의 글자와 스캔된 쪽을 한국어+영어로 읽어서 보이지 않는 글자층으로 넣어요. 이미 OCR된 쪽은 건너뛰어요.
- **검색 검사**: 바뀐 PDF에서 쪽마다 실제로 검색되는 글자를 보여 주고, 낱말을 검색해서 어디서 찾아지는지 표시해요. OCR로 읽은 낱말은 신뢰도(높음/보통/낮음)에 따라 색으로 보여 줘요.

| 어디서 | 어떻게 |
|---|---|
| 아이패드 | Safari로 주소 열기 → 공유 → **홈 화면에 추가** (앱처럼 쓰고 글꼴도 안 지워져요) |
| 윈도우 노트북 | Edge/Chrome으로 같은 주소 |

## 글꼴

기본 글꼴 4개가 사이트에 들어 있어서 **어느 기기에서 열든 따로 설정할 필요가 없어요.** 처음 열 때 한 번 받아 두고(약 23MB) 다음부터는 저장된 걸 써요.

| 자리 | 기본 글꼴 |
|---|---|
| 바탕 보통 (기본 본문) | KoPubWorld 바탕체 Pro Medium |
| 바탕 굵게 | KoPubWorld 바탕체 Pro Bold |
| 고딕 보통 | Apple SD Gothic Neo Medium |
| 고딕 굵게 | Apple SD Gothic Neo SemiBold |

다른 글꼴을 쓰고 싶으면 칸을 눌러 TTF/OTF 파일을 고르면 돼요(그 기기에만 저장). **기본 글꼴로 되돌리기**로 원래대로.

## 쓰는 법

1. 강의자료를 끌어다 놓거나 눌러서 고르기 (여러 개 가능)
2. 끝나면 **받기**(아이패드: 파일 앱 다운로드 폴더) / **공유**(굿노트 등으로 바로) / **검사하기**
3. 결과 파일 이름은 `원래이름_글꼴.pdf`

**변환 설정**
- 바꾸는 방식: 원래 계열 따라(기본) / 본문 바탕·제목 고딕 / 전부 바탕 / 전부 고딕
- OCR: 자동(그림 속 글자·스캔 쪽) / 모든 쪽 / 끄기
- 기울임 글씨는 기울여서 바꾸기, 고정폭(코드·염기서열) 글꼴은 그대로 두기

**글꼴별로 보기 · 바꾸기**: 결과 카드에서 파일 안에 있던 글꼴 목록과 무엇으로 바뀌었는지 보여 줘요. 마음에 안 들면 글꼴마다 고딕/바탕/그대로를 골라 **이 설정으로 다시 변환**.

## PPTX · DOCX

글꼴 *이름*을 바꿔 줘요(슬라이드, 레이아웃, 마스터, 테마, 표, 차트, 노트 / 본문, 스타일, 머리글·바닥글). 파워포인트·워드에서 새 글꼴로 보이려면 **그 컴퓨터에 글꼴이 설치돼 있어야** 해요(윈도우: 글꼴 파일 우클릭 → 설치). OCR까지 하고 싶으면 PDF로 내보낸 뒤 그 PDF를 다시 넣어 주세요.

## 잘 안 될 때

- **글자가 깨져 보임**: 원본 PDF의 글자 정보(ToUnicode)가 잘못된 드문 경우예요. 검사하기 → 원본 보기로 비교하고, 그 글꼴을 *그대로*로 바꿔 다시 변환하세요.
- **OCR이 틀림**: 검사 화면에서 빨간 상자(신뢰도 낮음)를 확인하세요. 그림 속 글자는 그림 그대로 보이고, 검색용 글자만 보이지 않게 들어가 있어요.
- **암호 걸린 PDF**: 여는 암호를 푼 뒤 넣어 주세요.
- **처음 OCR이 느림**: OCR 엔진과 한국어·영어 데이터(약 9MB)를 처음 한 번 받아요. 다음부터는 저장된 걸 써요.

## 구성

```
index.html, app.js           화면 (파일 넣기, 설정, 결과, 검사 화면)
engine/worker.js             PDF 처리 (백그라운드)
engine/pdf-swap.js           PDF 글꼴 교체 — 내용 스트림의 글자 출력만 새 글꼴로 바꿔 씀
engine/pdf-lexer.js          PDF 내용 스트림 해석
engine/pdf-fonts.js          원래 글꼴의 코드·폭·유니코드 해석 (Type0/TrueType/Type1/Type3)
engine/pdf-pages.js          쪽 분석, OCR용 렌더링(글자 뺀 그림), 보이지 않는 OCR 글자층
engine/classify.js           글꼴 이름 → 고딕/바탕/기호/고정폭 + 굵기 판별
engine/subset.js             HarfBuzz로 새 글꼴을 쓴 글자만 남기기
engine/office.js             PPTX/DOCX 글꼴 이름 교체
engine/ocr-format.js         Tesseract 결과 정리
vendor/                      MuPDF.js, HarfBuzz, Tesseract.js, JSZip
ocr/lang/                    한국어·영어 OCR 데이터 (tessdata best_int)
fonts/                       기본 글꼴 4개
sw.js, manifest.webmanifest  홈 화면 앱 · 오프라인
```
